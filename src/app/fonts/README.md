# Bundled site fonts

Playfair Display (Latin, variable 500–700) and Lato (Latin, 400/700) are the unchanged WOFF2 resources emitted by this site's successful Google Fonts / Next build on October 26, 2026. They preserve the existing typography while removing the build-time font-network dependency. These subsets match the previous `subsets: ["latin"]` configuration.

Upstream license records, retrieved October 26, 2026:

- https://raw.githubusercontent.com/google/fonts/main/ofl/playfairdisplay/OFL.txt
- https://raw.githubusercontent.com/google/fonts/main/ofl/lato/OFL.txt

The corresponding copyright and SIL Open Font License 1.1 texts are included alongside the fonts. Font files are not relicensed by this repository's public visibility. No font outlines were modified.
